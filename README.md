# 마왕 토벌 — 어둠의 용사

> 브라우저에서 바로 실행되는 순수 JavaScript 턴제 RPG

---

## 🎮 게임 소개

마왕 다르카스의 위협으로 황폐해진 마을을 재건하고, 던전을 탐험하며 성장해 마왕을 쓰러뜨리는 턴제 RPG입니다.

- **직업 선택**: 기사 / 마법사 / 궁수
- **동료 시스템**: 힐러(리온) / 탱커(카인) / 마법사(엘린) / 궁수(아리아) — 호감도 스토리 포함
- **던전 탐험**: 탑다운 캔버스 맵, FOG OF WAR
- **마을 성장**: 투자 → 폐허 → 공사중 → 번화가 → 번영 4단계
- **은행 시스템**: 예금·출금·이자 자동 적립
- **미니게임**: 여관에서 동료와 카드 게임 — 호감도 보상
- **업적 27개**: 전투·탐험·마을·동료·성장 카테고리
- **5슬롯 세이브**: localStorage 기반 멀티 세이브

## 🧩 던전 시스템

- **맵 생성**: BSP 방식 랜덤 (최대 8개 방 + 복도 연결)

- **수호자 카운트**: 5회 처치 시 마왕 전투 or 다음 층 진행
- **타일 오브젝트**: 적(👺) · 보스(👹) · 보물상자(📦) · 출구(🚪) · 함정의 방(🕳)

## 🕳 던전 기믹 — 함정의 방 (지뢰찾기 퍼즐)

층마다 고정으로 1개씩 등장하는 특수 방(튜토리얼인 성 밖 사냥터에는 등장하지 않음). 입장하면 던전 위에 지뢰찾기 퍼즐이 오버레이로 뜨며, 그 동안은 이동이 잠긴다.

- **첫 클릭 안전 보장**: 처음 여는 칸과 그 주변 8칸에는 지뢰가 배치되지 않는다.
- **클리어 시 보상**: 안전한 칸을 모두 열면 층 깊이·던전 위험도에 비례한 대량의 골드·경험치, 그리고 일정 확률로 직업에 맞는 등급 높은 무기를 획득한다.
- **함정 발동 시 페널티**: 지뢰 칸을 열면 중독 또는 화상 상태이상에 걸리며, 다음 전투에서 매 턴 피해를 입는다. 보상 없이 방을 나가게 된다.
- **난이도**: 숲 던전이 가장 작고 쉬우며, 심연 던전이 가장 크고(최대 8×8) 지뢰 비율도 높다.
- 부담 없이 떠나고 싶다면 **🚪 포기하고 나가기**로 언제든 페널티 없이 나갈 수 있다 (단, 보상도 없음).

## 🃏 미니게임 — 카드 게임

> 여관(🏨) → 여관 모달의 **카드 게임** 버튼으로 접근 (동료 모집 후 활성화)

상대와 3라운드 동안 카드를 내어 승부를 겨루는 미니게임입니다.
각 라운드에서 더 높은 카드를 낸 플레이어가 승리하며, 3라운드 종료 후 더 많은 승리를 거둔 플레이어가 최종 승자가 됩니다.

### 진행 방식

- 총 3라운드 진행
- 각 라운드마다 **카드 뽑기** 버튼으로 카드 1장 선택
- 숫자가 높은 쪽이 해당 라운드 승리 (A가 가장 강함 — 14)
- 3라운드 종료 후 승리 횟수 비교

### 카드 강도 순서

```
A(14) > K(13) > Q(12) > J(11) > 10 > 9 > ... > 2
```

### 결과 보상

| 결과 | 조건 | 호감도 보상 |
|---|---|---|
| 🏆 승리 | 2승 이상 | ❤ +5 |
| 🤝 무승부 | 승수 동률 | ❤ +2 |
| 💔 패배 | 상대가 2승 이상 | ❤ +1 |
| 🚪 포기 | 중도 포기 | ❤ +1 |

결과와 관계없이 함께한 시간만으로도 호감도를 얻을 수 있습니다.

호감도가 쌓이면 동료 궁극기 해금(30), 공격력 보너스(50), 스토리(75), EX 궁극기(100) 순으로 보상이 주어집니다.

## ⚖ 밸런스 규칙 (곡선 2)

모든 수치는 `balance.js`에 있고, `npm run balance`로 레벨별 결과를 볼 수 있습니다.

| 항목 | 규칙 |
|---|---|
| 최고 레벨 | **50** (스킬 포인트 레벨당 1점 → 최대 49점) |
| 필요 경험치 | `100 + 30 × (레벨-1)^1.65` (Lv10 1,226 / Lv30 7,863 / Lv49 17,930) |
| 몬스터 능력치 | `기본값 × (1 + 0.085 × (유효레벨-1)) × 층 난이도`. 유효레벨 = `기준레벨 + (내 레벨 - 기준레벨) × 0.35` (구역·층마다 기준 레벨이 있다) |
| 보스 | 그 층 배수 × 구역별 보스 배수 (`BOSS_DIFFICULTY`) |
| 전투 보상 | 골드·경험치 모두 몬스터 능력치 배수만큼 증가 (깊은 층일수록 더 번다) |
| 방어 | 비율 감쇠: `피해 = 공격 × 100 / (100 + 방어)`, 공격이 있으면 최소 1. 직업·동료 기본 방어도 반영 |
| 회복 | 회복 스킬 = 최대 HP의 20% (최소 25), 물약 = 최대 HP의 35% (최소 50) |

기준 지역(일반 던전 2층, 기사, 상점 최고 장비)에서 전투당 HP 손실은 레벨 1~50 내내 약 21~28%이고,
레벨당 필요 처치 수는 Lv10 6마리 → Lv30 19마리 → Lv50 29마리로 완만하게 늘어납니다.

## 🧪 개발 · 테스트

빌드 과정은 없습니다. `package.json`은 테스트/시뮬레이션 스크립트용입니다 (Node 20 이상).

```bash
npm test                 # 단위 테스트 (밸런스 수식 동등성, 세이브 마이그레이션·보안, 시뮬레이터)
npm run balance          # 밸런스 시뮬레이터 표 (기본: 기사 / 상점 최고 장비 / 일반 던전 2층)
node tools/balance-sim.js --zone abyss:3 --class tanker --gear starter --max 40
npm run balance:check    # 목표 곡선(tools/balance-sim.js 의 TARGETS)과 비교, 어긋나면 종료 코드 1
npm run balance:full     # 풀 키트 시뮬레이터: 실제 BattleManager 로 동료·궁극기·직업 스킬·물약까지 포함해 던전 층 클리어율 계단표를 출력
node tools/fullkit-sim.js --fight normal:3 --level 20 --class mage --gear shop   # 한 지역·레벨 상세
node tools/fullkit-sim.js --compare   # 직업 × 장비 가정 비교
```

- **밸런스 수치는 `balance.js`에서만 고칩니다.** 경험치 곡선을 바꾸면 `Balance.CURVE_ID`를 1 올리세요.
  기존 세이브의 레벨 내 진행도는 불러올 때 새 곡선에 비율로 옮겨집니다.
- **세이브 구조를 바꾸면 `save-schema.js`의 `SAVE_VERSION`을 올리고 마이그레이션을 추가**하세요.
  저장 데이터는 신뢰할 수 없는 입력으로 취급합니다(프로토타입 오염·타입 혼동·HTML 주입 방어).
  옛 세이브를 처음 열 때 원본이 `rpgSave_slot_N_v{버전}c{곡선}` 키에 한 번 백업되고,
  저장할 때마다 직전 저장이 `rpgSave_slot_N_bak`에 남습니다.
- `tests/sim.test.js`의 "목표 곡선" 테스트는 밸런스 개편 전까지 `todo`입니다.

## 🛠 개발 이력

### v2.6 — 동료 균형
- 동료 1명만 데려갔을 때 전투 부담(항구 1층, 기사 Lv28): 엘린(마법사) 10% ≪ 카인(탱커) 33% ≈ 리온(힐러) 40% ≈ 아리아(궁수) 47%. 엘린의 궁극기가
  주인공 공격력의 5~13배라 한 방에 끝났고, 아리아의 궁극기는 동료 공격력만 써서 후반에 따라가지 못했다
- 엘린 궁극기 5/8/8/13배 → 3.5/5.5/6/8배, 아리아 궁극기 타당 피해에 주인공 공격력 25% 추가 (`Balance.PARTY_ULT`)
- 결과: 엘린 27% · 카인 33% · 리온 40% · 아리아 37%. 동료 조합별 클리어율은 91~94%로 수렴

### v2.5 — 직업 균형
- 풀 키트 시뮬레이터로 확인한 격차: 같은 기준 구역에서 탱커·힐러는 거의 100%, 마법사·궁수는 0%였다. 원인은 마법사·궁수의 낮은 방어/HP와
  탱커의 방패 강타 방어 태세·힐러의 전체 회복 궁극기였다
- 직업별 레벨업 성장(`Balance.CLASS_GROWTH`): 마법사 HP+28/공+7, 궁수 HP+30/공+7.5, 탱커 HP+18/공+4.5, 힐러 HP+17/공+4 (기본 HP+20/공+5)
- 힐러 궁극기 회복 100% → 25%, 힐러 직업 스킬 회복 4%, 축복 패시브 +10/20/30%, 탱커 방패 강타 방어 1회, 힐러 기본 HP 190/공격 38
- 결과(기준 구역 3층, 상자 장비, 6개 구역 평균 클리어율): 기사 84% · 탱커 92% · 마법사 88% · 궁수 87% · 힐러 86%.
  힐러는 초반(일반 3층 Lv15)에 50%로 약하고 후반에 강하다 — 회복 비율 기반 성장의 특성
- 이미 육성한 캐릭터의 능력치는 그대로이고, 새로 오르는 레벨부터 직업별 성장이 적용된다

### v2.4 — 구역 난이도 정비 · 직업 스킬 버그 수정
- **구역 난이도**: 몬스터가 플레이어 레벨을 그대로 따라가서 어느 구역이든 레벨과 무관하게 같은 난이도였다(풀 키트 시뮬레이터로 확인).
  구역·층마다 기준 레벨(`FLOOR_LEVEL`)을 두고 몬스터가 레벨을 35%만 따라가게 바꿈. 기사·상자 장비 기준 편안해지는 레벨:
  일반 3층 15 → 광산 3층 약 25 → 항구 3층 27 → 엘프숲 3층 35 → 수도 3층 39 → 심연 3층 47
- 층 배수(`FLOOR_DIFFICULTY`)와 보스 배수(`BOSS_DIFFICULTY`)를 시뮬레이터로 재조정 (엘프숲 보스처럼 기본 능력치 대비 벽이던 보스 완화)
- 버그: 기사·탱커·힐러에게 패시브 스킬 목록이 비어 있던 문제(키 `warrior`/`knight` 불일치), 탱커·힐러에게 직업 스킬이 없던 문제
  (탱커 🛡 방패 강타, 힐러 ✨ 성스러운 빛 추가, 힐러 패시브 ✨ 축복 추가), 몬스터 기절이 아무 효과도 없던 문제(기절한 적은 반격하지 못함, 보스는 1턴만)
- 도구: `npm run balance:full` (풀 키트 시뮬레이터)

### v2.3 — 밸런스 개편
- 최고 레벨 99 → 50, 경험치 곡선을 지수(×1.3)에서 완만한 거듭제곱으로 변경 (곡선 2). 이전에는 레벨 20 부근에서 막혔고
  (Lv20 다음 레벨까지 157마리, Lv30 2,152마리) 레벨이 오를수록 전투가 더 위험해졌습니다 (전투당 HP 손실 Lv10 19% → Lv30 62%)
- 몬스터 성장률 +15% → +8.5%/레벨, 전투 보상이 몬스터 배수와 함께 증가
- 방어를 정액 차감에서 비율 감쇠로 (초반엔 방어가 공격을 넘어 피해 0, 후반엔 방어가 무의미했던 문제 해결). 사용되지 않던 직업 기본 방어와 1번 동료 기본 방어를 반영
- 회복을 최대 HP 비율로 (기존 고정 +25/+50은 레벨 20에서 최대 HP의 5%/9%)
- 기존 세이브는 불러올 때 레벨 내 진행 비율을 유지한 채 새 곡선으로 변환되며, 레벨 50 초과분은 50으로 맞춰집니다 (원본은 자동 백업)
