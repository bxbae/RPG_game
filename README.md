# 마왕 토벌 — 어둠의 용사

> 브라우저에서 바로 실행되는 순수 JavaScript 턴제 RPG

---

## 🎮 게임 소개

마왕 다르카스의 위협으로 황폐해진 마을을 재건하고, 던전을 탐험하며 성장해 마왕을 쓰러뜨리는 턴제 RPG입니다.

- **직업 선택**: 기사 / 마법사 / 궁수
- **동료 시스템**: 힐러(리온) / 탱커(카인) / 마법사(엘린) / 궁수(아리아) — 호감도 스토리 포함
- **던전 탐험**: 탑다운 캔버스 맵, FOG OF WAR
- **마을 성장**: 투자 → 폐허 → 공사중 → 번화가 → 번영 4단계
- **은행 시스템**: 예금·출금·이자 자동 적립
- **미니게임**: 여관에서 동료와 카드 게임 — 호감도 보상
- **업적 27개**: 전투·탐험·마을·동료·성장 카테고리
- **5슬롯 세이브**: localStorage 기반 멀티 세이브

## 🗂 파일 구조

```
rpg-game/
├── index.html              ← 진입점 (스크립트 로딩 순서 관리)
├── rpg-main.css            ← 통합 스타일
├── models.js               ← 데이터 모델 & 상수 (직업/몬스터/아이템/던전)
├── managers.js             ← SaveManager / ItemManager / QuestManager
├── achievement-system.js   ← 업적 27개 정의 & 토스트 팝업
├── battle-manager.js       ← 턴제 전투 로직 (상태이상/스킬/궁극기)
├── dungeon-scene.js        ← 탑다운 맵 (캔버스 렌더, FOG, 이동)
├── trap-room.js            ← 던전 "함정의 방" 기믹 (지뢰찾기 퍼즐)
├── battle-scene.js         ← 전투 UI (SD 이미지, HUD, 컷신)
├── town-scene.js           ← 마을 UI (은행/투자/스킬/대장간/저장)
├── dialogue-scene.js       ← 동료 스토리 대화 씬 (호감도별 4단계)
├── card-game.js            ← 주막 카드 게임 미니게임 (하이카드 승부)
├── game.js                 ← 메인 컨트롤러 (씬 전환, 던전 층수)
├── images/                 ← SD 캐릭터 이미지, 배경, 포트레이트
├── sounds/                 ← BGM / SFX
└── video/                  ← 궁극기 컷신 영상
```

## ⚔ 씬 흐름

```
타이틀 (오프닝 연출 → 직업 선택)
  │
  ▼
마을 (TownScene)
  ├─ 던전 진입 → DungeonScene (탑다운 맵 탐험)
  │     └─ 적 접촉 → BattleScene (턴제 전투)
  │           ├─ 승리 → 던전 복귀 (맵 유지)
  │           ├─ 수호자 5회 처치 → 마왕 전투
  │           └─ 마왕 처치 → 승리 화면 + 심연 해금
  ├─ 심연 (마왕 처치 후)
  ├─ 도시 탐험 (마을 번영 달성 후)
  ├─ 은행 (예금·투자)
  ├─ 동료 모집 → 호감도 쌓기 → 대화 씬 자동 트리거
  ├─ 스킬 트리 (액티브 + 직업별 패시브)
  ├─ 퀘스트 → 완료 시 마을 자동 복귀
  └─ 저장/불러오기 (5슬롯)
```

## 🧩 던전 시스템

- **맵 생성**: BSP 방식 랜덤 (최대 8개 방 + 복도 연결)
- **FOG OF WAR**: 탐색 반경 4타일만 공개
- **층수 구조**: 던전 1~3층 → 마왕 / 심연 1층 / 도시 1층
- **수호자 카운트**: 5회 처치 시 마왕 전투 or 다음 층 진행
- **타일 오브젝트**: 적(👺) · 보스(👹) · 보물상자(📦) · 출구(🚪) · 함정의 방(🕳)

---

## 🕳 던전 기믹 — 함정의 방 (지뢰찾기 퍼즐)

층마다 고정으로 1개씩 등장하는 특수 방(튜토리얼인 성 밖 사냥터에는 등장하지 않음). 입장하면 던전 위에 지뢰찾기 퍼즐이 오버레이로 뜨며, 그 동안은 이동이 잠긴다.

- **첫 클릭 안전 보장**: 처음 여는 칸과 그 주변 8칸에는 지뢰가 배치되지 않는다.
- **클리어 시 보상**: 안전한 칸을 모두 열면 층 깊이·던전 위험도에 비례한 대량의 골드·경험치, 그리고 일정 확률로 직업에 맞는 등급 높은 무기를 획득한다.
- **함정 발동 시 페널티**: 지뢰 칸을 열면 중독 또는 화상 상태이상에 걸리며, 다음 전투에서 매 턴 피해를 입는다. 보상 없이 방을 나가게 된다.
- **난이도**: 숲 던전이 가장 작고 쉬우며, 심연 던전이 가장 크고(최대 8×8) 지뢰 비율도 높다.
- 부담 없이 떠나고 싶다면 **🚪 포기하고 나가기**로 언제든 페널티 없이 나갈 수 있다 (단, 보상도 없음).

## 👥 동료 시스템

| 동료 | 클래스 | 궁극기 | 호감도 100 보상 |
|---|---|---|---|
| 리온 | 힐러 | 천상의 기적 (전체 회복) | EX 기적 + 가드 |
| 카인 | 탱커 | 절대수호 (피해 감소) | EX 수호 10턴 |
| 엘린 | 마법사 | 아포칼립스 (고배율 마법) | EX 8배 폭딜 |
| 아리아 | 궁수 | 폭풍 사격 (다중 타격) | EX 10연타 |

호감도 30 → 궁극기 해금 / 50 → 공격력 보너스 / 75 → 스토리 해금 / 100 → EX 궁극기

## 🃏 미니게임 — 카드 게임

> 여관(🏨) → 여관 모달의 **카드 게임** 버튼으로 접근 (동료 모집 후 활성화)

상대와 3라운드 동안 카드를 내어 승부를 겨루는 미니게임입니다.
각 라운드에서 더 높은 카드를 낸 플레이어가 승리하며, 3라운드 종료 후 더 많은 승리를 거둔 플레이어가 최종 승자가 됩니다.

### 진행 방식

- 총 3라운드 진행
- 각 라운드마다 **카드 뽑기** 버튼으로 카드 1장 선택
- 숫자가 높은 쪽이 해당 라운드 승리 (A가 가장 강함 — 14)
- 3라운드 종료 후 승리 횟수 비교

### 카드 강도 순서

```
A(14) > K(13) > Q(12) > J(11) > 10 > 9 > ... > 2
```

### 결과 보상

| 결과 | 조건 | 호감도 보상 |
|---|---|---|
| 🏆 승리 | 2승 이상 | ❤ +5 |
| 🤝 무승부 | 승수 동률 | ❤ +2 |
| 💔 패배 | 상대가 2승 이상 | ❤ +1 |
| 🚪 포기 | 중도 포기 | ❤ +1 |

결과와 관계없이 함께한 시간만으로도 호감도를 얻을 수 있습니다.

호감도가 쌓이면 동료 궁극기 해금(30), 공격력 보너스(50), 스토리(75), EX 궁극기(100) 순으로 보상이 주어집니다.
